# Link Target Switching

Choose **per click** whether a web link opens in Obsidian's built-in **Web viewer** or in your **system browser**, without going through the right-click menu.

With the Web viewer core plugin, every external link opens inside Obsidian. That is great for quick reading, but sometimes you want the real browser (logins, extensions, downloads). Until now the only way was right-click, then "Open in default browser". This plugin makes that a single click.

## How it works

| Action | Result |
|---|---|
| Click a web link | Opens in your **default target** |
| **Alt** + click (or Shift, configurable) | Opens in the **other** target |
| Click `🔗 Web viewer` / `🔗 Browser` in the status bar | Flips the default |
| Ctrl / Cmd + click | Left to Obsidian's normal behaviour |

Works in Reading view, Live Preview, Source mode, canvas cards and hover previews, for `[text](https://...)` links, `<https://...>` links and bare URLs.

## Commands

All commands can be bound to a hotkey in **Settings → Hotkeys**.

- **Toggle default link target (Web viewer / browser)**
- **Open link under cursor in browser**
- **Open link under cursor in Web viewer**
- **Open current Web viewer page in browser**: hands the page you are reading in the Web viewer over to your browser.

## Settings

- **Default target**: Web viewer or Browser.
- **Switch key**: Alt / Option or Shift.
- **Show in status bar**: show or hide the status bar toggle.

## Requirements

- Obsidian 1.8.0 or newer, desktop only.
- The **Web viewer** core plugin enabled (Settings → Core plugins). If it is off, links fall back to your browser.

## Installation

### From Community plugins

Settings → Community plugins → Browse → search for **Link Target Switch** → Install → Enable.

### Manually

1. Download `main.js` and `manifest.json` from the [latest release](../../releases/latest).
2. Put them in `<your vault>/.obsidian/plugins/link-target-switch/`.
3. Reload Obsidian and enable **Link Target Switch** under Settings → Community plugins.

## Privacy

The plugin makes no network requests of its own and collects no data. It only decides where a link you click is opened.
